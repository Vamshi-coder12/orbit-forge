# ORBIT_FORGE

Vite + React single-page concept site integrating the supplied StaggeredMenu and Antigravity configurations with TextPressure, StarBorder, Radar, Topography, Binary Orbits, Arc Cursor, Lightning, and a preserved 3D-ready visual slot.

## Run
npm install
npm run dev

## Build
npm run build

## Public deployment
This is a Vite static site. For a public URL, deploy the project root to a static host such as Vercel or Netlify. No server is required.

Build command: `npm run build`

Output directory: `dist`
